# ReRoute App: Feature Updates & Refinements

## 1. Global Navigation & Social Integration
*   **Navigation Bar Optimization:** The bottom navigation has been consolidated into three primary tabs: Home, Trip, and Profile.
*   **Social Feed Restructuring:** The standalone "Community" tab has been deleted and merged into the "Home" tab. 
*   **Trip Interaction:** Users can share trips for public viewing, but interactions are now restricted strictly to "starring" (saving) a trip; liking and commenting are no longer supported. All starred trips are accessible within the user's Profile.
*   **Discover Module:** The "Friend's Trip" feature has been rebranded as "Discover," allowing users to browse trip reviews from friends or the wider public, complete with search filters.

---

## 2. Trip Room (Core Experience)
*   **Dynamic Theming:** Trip rooms will now feature dynamic theme colors that change based on specific weather conditions.
*   **Active Trip Routing:** The system restricts users to only one "live" (active) trip at a time. When a trip is currently live, navigating to the Trip section will automatically bypass the selection screen and route the user directly into the active Trip Room. 
*   **Room State Management:** Users must manually exit the live Trip Room when necessary. Trips are archived either manually by the user or automatically when the trip dates expire.

---

## 3. High-Priority Trip Planning Additions
*   **User Preferences Module:** A comprehensive preference selection form has been added to tailor trip generation. The parameters include:
    *   **Travel Companions:** Solo, Family, Couple, Friends, Elderly.
    *   **Travel Style:** Cultural, Classic, Nature, Cityscape, Historical.
    *   **Travel Pace:** Ambitious, Moderate, Relaxed.
*   **Modular Itinerary Suggestions:** The system now generates specific suggestions for transportation, accommodations, and attractions, optimized based on factors like time and money. 
*   **Itinerary Structure:** Daily plans feature an editable title, a notes section, and categorized additions for "How to Get There" (+ Transportation), "What to See & Do" (+ Attractions), and "Where to Stay" (+ Stay).

---

## 4. AI, Safety, & Utilities
*   **App Mascot / AI Assistant:** A newly introduced App Mascot will serve as an AI assistant, delivering system notifications directly to the user.
*   **Proactive Safety & Weather Analysis:** The AI assistant continuously analyzes planned destinations against real-time weather and risk data. If a location is flagged as risky, the system triggers instant, alternative itinerary suggestions.
*   **Global SOS:** The SOS emergency button is now persistently accessible from everywhere within the app interface while a trip is currently live.
*   **Map Refinements:** The primary map functionality has been shifted to focus heavily on itinerary and trip planning using a standard route planning algorithm. The 3D model feature is retained but is now prioritized for showing real photographs and practical location information, such as precise drop-off points.
*   **Language Tool:** A real-time translator has been integrated into the app.
